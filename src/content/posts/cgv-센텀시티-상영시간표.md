CGV 센텀시티는 국내 유일의 스타리움(STARIUM)관을 비롯해 다양한 특별관을 갖춘 명소예요. 다만 백화점 내부에 있어 주차 동선과 영업시간 외 입장이 헷갈릴 수 있어요.

## 실시간 상영시간표 확인 방법

상영 시간은 매일 유동적으로 바뀌고 당일에도 조정될 수 있어요. 방문 전 반드시 실시간 정보를 확인하세요.

| 단계 | 방법 |
| --- | --- |
| 1 | CGV 공식 홈페이지·앱 접속 |
| 2 | 극장 메뉴 → '부산/울산' → 'CGV 센텀시티' |
| 3 | 날짜·영화 선택 후 예매 (특별관 여부 확인) |

## 특별관 라인업

- **스타리움(STARIUM)관** — 국내 유일 초대형 스크린. 대작 블록버스터에 추천.
- **ULTRA 4DX & SCREENX** — 4D 효과 + 좌우 벽면 스크린. 액션 영화 시 인기.
- **씨네드쉐프** — 5층, 90석. 침대형 좌석 + 파인다이닝 프리미엄관.

## 주차 이용 안내

신세계백화점 주차장을 공유해요.

- 영화 관람 시 기본 **3시간 무료 주차**
- 모바일 티켓·지류 티켓의 주차 바코드를 **무인 사전 정산기**에 인식
- 극장과 가까운 **C GATE** 구역 주차 권장

## 영업시간 외·휴점일 입장

백화점 영업 외 시간에는 지하 주차장 → 지하 2층 '엘리베이터홀 3' → 7층 영화관 직행이 가장 빨라요.

| 구분 | 내용 |
| --- | --- |
| 주소 | 부산 해운대구 센텀남대로 35, 신세계백화점 7층 |
| 규모 | 총 10개관 / 2,152석 |
| 특이사항 | 씨네드쉐프는 5층 별도 |

연중무휴로 운영되며, 백화점 휴무일에도 전용 통로로 입장할 수 있어요.
